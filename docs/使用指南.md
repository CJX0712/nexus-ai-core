## 1. Web 控制台

`docker compose up` 后访问 http://localhost:8080 （本地开发为 http://localhost:5173）。

| 页面 | 用途 |
|------|------|
| 对话 | 直接提问；勾选"启用知识库"后走检索增强，回答下方显示来源数 |
| 知识库 | 粘贴文本或上传文件入库；检索命中与溯源问答结果同屏展示 |
| 智能体 | 下达任务，查看每一步的 思考 / 行动 / 观察 与最终结论 |
| 工作流 | 用 JSON 定义 DAG 节点，运行后查看拓扑顺序与各节点输出 |
| 系统状态 | 查看嵌入提供方、模型降级链、已注册工具、知识库统计 |

## 2. REST API 示例

### 2.1 健康检查

```bash
curl http://localhost:8000/health
```

```json
{
  "status": "ok", "version": "1.0.0",
  "embedding_provider": "hashing",
  "llm_chain": ["offline_extractive"],
  "rag_chunks": 0, "documents": 0
}
```

### 2.2 文本入库 / 文件入库

```bash
curl -X POST http://localhost:8000/v1/rag/ingest -H "Content-Type: application/json" \
  -d '{"text":"报销需要提交发票与审批单，审批通过后 5 个工作日到账。","source":"finance.md"}'

curl -X POST http://localhost:8000/v1/rag/ingest-file \
  -F "file=@./手册.pdf"
```

响应：`{"doc_id":"...","n_chunks":3,"source":"finance.md"}`

### 2.3 混合检索

```bash
curl -X POST http://localhost:8000/v1/rag/search -H "Content-Type: application/json" \
  -d '{"query":"报销流程","top_k":3}'
```

### 2.4 溯源问答

```bash
curl -X POST http://localhost:8000/v1/rag/ask -H "Content-Type: application/json" \
  -d '{"question":"报销多久到账？","top_k":3}'
```

返回 `answer` + `sources[]`（含 `doc_id`/`score`/`source`/`snippet`）。

### 2.5 对话（可带会话记忆）

```bash
curl -X POST http://localhost:8000/v1/chat -H "Content-Type: application/json" \
  -d '{"message":"总结一下报销政策","session_id":"u-1001","use_rag":true,"top_k":4}'
```

### 2.6 运行智能体

```bash
curl -X POST http://localhost:8000/v1/agent/run -H "Content-Type: application/json" \
  -d '{"task":"先检索知识库里关于报销的内容，再计算 3 笔 1200 元的总额","max_steps":6}'
```

返回 `answer` + `steps[]`（每步含 thought/action/action_input/observation）。

### 2.7 运行工作流

```bash
curl -X POST http://localhost:8000/v1/workflow/run -H "Content-Type: application/json" \
  -d '{
    "input": "报销",
    "nodes": [
      {"id":"topic","kind":"transform","params":{"template":"主题:{input}"},"depends_on":[]},
      {"id":"recall","kind":"rag","params":{"query":"{input}","top_k":3},"depends_on":[]},
      {"id":"calc","kind":"tool","params":{"name":"calculator","args":{"expression":"1200*3"}},"depends_on":["topic"]}
    ]
  }'
```

返回 `order`（拓扑顺序）与 `outputs`（各节点输出）。

### 2.8 记忆读写

```bash
curl -X POST http://localhost:8000/v1/memory/u-1001 -H "Content-Type: application/json" \
  -d '{"role":"user","content":"我偏好中文回答"}'

curl "http://localhost:8000/v1/memory/u-1001?n=10"
curl -X POST "http://localhost:8000/v1/memory/u-1001/recall?query=偏好&limit=5"
curl -X DELETE http://localhost:8000/v1/memory/u-1001
```

## 3. Python 直接调用（绕过 HTTP）

```python
from app.core.config import Settings
from app.container import Container

c = Container(Settings.from_env())

c.rag.ingest_text("发票需要在 30 天内提交。", source="policy.md")
hits = c.rag.search("发票时限", top_k=3)
answer = c.rag.answer("发票多久内要提交？", c.gateway)

print(answer.answer, answer.sources)
c.persist()   # 向量库落盘
```

## 4. 扩展指南

### 4.1 新增一个工具（自动被智能体感知）

```python
from app.agent.tools import Tool, ToolRegistry

def weather(city: str) -> str:
    return f"{city}：晴，26℃"

reg = ToolRegistry()
reg.register(Tool(
    name="weather",
    description="查询城市天气。",
    parameters={"type":"object","properties":{"city":{"type":"string"}},"required":["city"]},
    func=weather,
))
```

要让它进入默认工具集，在 `app/agent/tools.py` 的 `build_default_registry` 中注册即可。

### 4.2 新增一个 LLM provider

在 `app/gateway/llm.py` 中实现 `complete()`，然后在 `build_llm_gateway` 里加入降级链：

```python
chain.append(MyProvider(...))
```

### 4.3 新增一个工作流节点类型

在 `app/workflow/engine.py` 的 `_run_node` 中增加一个 `if node.kind == "..."` 分支。

## 5. 调优建议

| 场景 | 建议 |
|------|------|
| 答案漏检 | 调小 `NEXUS_CHUNK_SIZE`（如 256）并增大 `NEXUS_TOP_K` |
| 答案啰嗦 | 降低 `NEXUS_LLM_TEMPERATURE`；修改 `app/rag/service.py` 的 `SYSTEM_PROMPT` |
| 关键词命中差 | 确认 `NEXUS_HYBRID_ENABLED=true`（BM25 生效） |
| 中文语义弱 | 换更好的嵌入模型，如 `NEXUS_EMBED_MODEL=BAAI/bge-base-zh-v1.5` |
| 智能体乱调用工具 | 降低 `NEXUS_AGENT_MAX_STEPS`，或在工具描述中写清适用场景 |
